# Introduction

This project will consist of recreating the Pacman game using a maze which will be provided to us from an external A_maze_ing project (not our own).
We will have to handle everything else: main menu, highscores, cheat mode (for review purposes).
We will have to use MLX or something similar to handle the visual side of things.


# How to run 

Kur ta lexosh ket keido bej kto:

1. mkdir venvs
2. python -m venv venvs/pygame_dependencies
3. source venv/pygame_dependencies/bin/activate
4. python main_menu_UI.py
